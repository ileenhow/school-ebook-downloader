# 智慧教育平台课本下载助手

这是一个适用于 Chrome 和 Microsoft Edge 的浏览器扩展，用于在国家中小学智慧教育平台查找和下载教材 PDF。

扩展支持按学段、学科、年级、出版社和册次筛选教材，也可以在教材列表页、详情页或扩展弹窗中直接发起下载。批量下载支持跨筛选勾选教材，并以最多 3 个并发任务解析下载地址。

## 使用方式

1. 安装扩展后，登录[国家中小学智慧教育平台](https://basic.smartedu.cn/)。
2. 点击浏览器工具栏中的扩展图标，通过筛选条件查找教材。
3. 点击单本教材的下载按钮，或勾选多本教材后批量下载。

在智慧教育平台的教材列表页和详情页中，也可以直接使用扩展添加的“下载 PDF”按钮。文件会保存到浏览器默认下载目录。

扩展本身没有用户系统，不会保存平台账号和密码；下载功能依赖浏览器中已有的平台登录状态。

## 本地开发

需要以下环境：

- Node.js 22.12.0 或更高版本
- pnpm 10 或更高版本
- Chrome 或 Microsoft Edge

安装依赖并启动监听构建：

```sh
nvm use
pnpm install
pnpm dev
```

开发产物输出到 `dist/`。打开 `chrome://extensions` 或 `edge://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，然后加载 `dist/` 目录。
